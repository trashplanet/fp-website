# Feral Protocol website

Static promotional site for the *Feral Protocol* science-fiction series.

## Preview locally

Run any static file server from this directory, for example:

```sh
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Email signup

The signup form currently shows a placeholder message and does not collect or send email addresses. Wire it to the chosen email provider before launch.
